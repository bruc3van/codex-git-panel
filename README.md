# Codex Git Panel MVP

本地 Codex 插件，在内置浏览器中提供接近 VS Code 布局的手动 Git 面板。

## 使用

安装插件后新建 Codex 任务，输入“打开 Git 面板”。也可在本仓库执行 `npm start`，使用输出的本地链接打开。要求 Node.js 20+、Git。

界面顶部输入提交说明，点击 Commit。已有暂存时只提交暂存内容；没有暂存时弹出文件清单，确认后暂存全部并提交。Ctrl+Enter 可提交。工作区干净且有待推送提交时，主按钮切换为 Push；有新更改时保持 Commit，历史区仍可推送。按钮下方解释当前条件。无上游时不能推送，但本地提交可用。

## MVP 范围

- 仓库和分支状态、文件级暂存/取消暂存、已跟踪文件放弃修改（确认后）。
- 工作区/暂存区统一差异、只读近期提交、暂存快照检查与直接提交。
- 获取、仅快进拉取、推送到已配置上游；无远端时禁用远端按钮。
- 深浅主题、拖动左右分栏、执行状态与错误反馈。

暂不提供 AI 生成说明、提交并推送下拉、独立全部暂存按钮、分块暂存、并排 diff、复杂分支图或冲突编辑。正在合并/变基或有冲突时需在终端处理。Git hook、签名及凭据沿用本机配置；需要交互的认证应先在终端完成。若全部暂存后提交失败，更改保留在暂存区，修正错误后可直接重试提交。

## 本地服务

源代码在 `plugins/git-panel`。服务只监听 127.0.0.1，绑定单一仓库，使用随机会话凭据并校验 Host/Origin。启动链接含会话凭据，不要对外分享。启动器复用对应源路径及仓库的存活进程，运行记录存放在 `%LOCALAPPDATA%/CodexGitPanel`。关闭浏览器不自动终止服务，可根据运行记录的 PID 停止相应 Node 进程。

插件安装后加载的是 Codex 缓存副本，修改源代码需更新缓存版本并重新安装，新任务加载更新。面板不向原生侧边栏注入按钮。

## 验证

`npm test` 使用临时仓库验证 Git 行为及 HTTP 访问边界。测试保留临时目录以便检查，不涉及真实用户仓库的提交或推送。
