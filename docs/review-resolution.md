# 整仓审查核实与处理（2026-09-10）

核实依据为当前源码、真实临时 Git 仓库、HTTP 请求、Windows / WSL Ubuntu 测试和 Chromium 浏览器运行结果。原有 3 项测试基线通过。

| 原审查项 | 核实结论与处理 |
| --- | --- |
| 1 Unix 崩溃恢复 | 成立。仅恢复当前用户拥有、连接返回 ECONNREFUSED 的 socket；独占恢复锁防止并发清理。启动器保留错误诊断并修正脚本路径。真实 SIGKILL 后并发恢复通过。 |
| 2 复用时泄露 token | 缺少 PID 校验、允许重定向成立。请求前排除死亡/无效 PID，并禁止重定向。PID 存活检查不能证明端口属于原服务，PID 重用仍是局限，不宣称完成进程身份认证。 |
| 3 记录写入失败泄漏服务 | 成立。失败后关闭 HTTP 连接、服务和实例锁；注入写入失败验证端口关闭且锁可重新获取。 |
| 4 Ctrl+Enter | 成立。与主按钮统一入口；真实浏览器验证提交后工作区干净时可继续触发 Push。 |
| 5 路径 / worktree | 部分成立：原仓库名已有完整路径 tooltip，worktree 不可见。增加可见类型和路径，长路径省略但可聚焦查看 tooltip。 |
| 6 路径判断 | 未复现平台失败，但两处实现确实不同。统一使用规范化根目录和 path.relative 边界判断。 |
| 7 UTF-8 分块 | 属于 bug。Buffer 按字节限额收集后统一解码；在中文字符内部拆包的提交测试通过。请求限额 64KB，提交说明原 10000 字符限制保留。 |
| 8 Unix 凭据权限 | 成立。改为用户私有运行目录 0700，新记录 0600；socket 放入短路径的用户私有目录以兼容系统长度限制。 |
| 9 大列表 / diff | 部分成立：Git 命令原有 4MB 输出限制，不是无限输出。每组只渲染 500 个文件且明确提示自动暂存仍包含全部；大 diff 使用纯文本。状态 API 保留完整文件列表，避免破坏冲突检查、切换分支和提交快照语义；超 4MB 明确提示终端处理。 |
| 10 窄栏布局 | 成立。600px 及以下预览占满内容区，关闭返回列表；420px、500px 和 1000px 实测通过。 |
| 11 视觉细节 | 警告色改为主题变量；刷新 / 放弃统一 SVG；移除 toggleHistory / commitHint 死样式；文件操作按钮增至 30px。未全面重写旧 CSS，也未将桌面按钮全部扩大到 44px。 |
| 12 工程配套 | 增加 Node >=20 声明、独立回归用例和 Windows/Linux/macOS × Node 20/22 CI 配置。私有根包没有必要额外引入版本号；已按作者选择添加 MIT LICENSE，并在 package.json 声明。原综合工作流测试保留。 |

新增测试还发现并修复：已暂存重命名文件再次暂存时，旧路径不存在导致 git add 失败。已验证 rename diff、discard、stage、unstage，以及 open 对脚本和不在文件列表中的路径的拒绝。

验证结果：Windows 7 通过、1 Unix 专属用例跳过；WSL Ubuntu 8 全部通过。浏览器验证了中文提交快捷键、Push、窄栏返回、worktree、深色主题、大 diff 和文件列表渲染上限。Git 操作仅发生于测试临时仓库，Push 指向本机临时裸仓库。git diff --check 通过。

边界：macOS 真机、Windows 默认应用成功启动未在本轮验证；CI 仅新增配置，尚未远端运行。Unix 恢复过程本身若被杀死会留下 .recovery 锁并停止自动清理，错误提示给出锁路径；确认相关启动进程均退出后可手动删除。旧版 Unix 服务升级前应先停止，避免运行目录迁移导致并行实例。未提交、推送、发布或重装插件。
